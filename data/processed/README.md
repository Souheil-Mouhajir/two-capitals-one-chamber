# Data dictionary

Nine files, all generated by the scripts in `src/` and all rebuilt by `make all`.
Ballots are recorded as `yes`, `abstain` or `no`. A blank cell means no ballot was
recorded for that state on that roll call, or that the cell held fewer than five
shared votes and was dropped.

## agreement_by_year.csv

One row per year per subject coding. Columns `agreement_MA_DZ` through
`agreement_DZ_GB` hold the agreement index in percent for thirteen dyads: Morocco
against Algeria, then each of them against the United States, France, China, Russia,
Spain and the United Kingdom.

| Column | Meaning |
| --- | --- |
| `year` | Calendar year of the roll call |
| `subject` | `all`, `important`, or one of the six Voeten issue flags: `me`, `co`, `hr`, `di`, `nu`, `ec` |
| `agreement_*` | Agreement index in percent, 1 for the same ballot, 0.5 for one abstention, 0 for opposition |
| `shared_roll_calls` | Roll calls where both Morocco and Algeria voted |

## positions_by_year.csv

| Column | Meaning |
| --- | --- |
| `year` | Calendar year |
| `morocco`, `algeria`, `united_states` | Position on the first dimension, unit standard deviation, signed so the United States is positive |
| `distance` | Moroccan position minus Algerian position |
| `distance_low`, `distance_high` | 95 percent interval from 200 bootstrap replications |
| `contested_roll_calls` | Roll calls that entered the estimate |
| `states` | States with a position that year |

## positions_by_period.csv

The same estimate pooled over 1962-1975, 1976-1991, 1992-2005 and 2006-2019, with
300 replications. Levels are comparable within a period and not across periods.

## agreement_gaps.csv

| Column | Meaning |
| --- | --- |
| `capital` | Reference state |
| `sample` | `important` for the State Department designation, `all` for the full agenda |
| `morocco`, `algeria` | Agreement rate in percent, 2000 to 2019 |
| `gap` | Moroccan rate minus Algerian rate, in percentage points |
| `ci_low`, `ci_high` | 95 percent interval from 2,000 bootstrap replications |
| `shared_roll_calls` | Roll calls where all three states voted |

## opposed_roll_calls.csv

The 88 roll calls where one voted yes and the other no, with the resolution symbol,
the title as recorded in the source file, the American and French ballots, and the
State Department importance flag.

## sahara_roll_calls.csv

Two tiers. `named` holds the 25 roll calls whose title or description matches Sahara,
Ifni, Rio de Oro or Saguia el Hamra. `proxy` holds the 68 recorded votes since 1991 on
the implementation of the Declaration on the Granting of Independence, the resolution
that now carries Western Sahara. The last three columns are the chamber tally.

## caucus_defection.csv

| Column | Meaning |
| --- | --- |
| `year` | Calendar year |
| `state` | Morocco or Algeria |
| `bloc` | `arab league` or `african group`, using the current rosters |
| `departures` | Ballots against the bloc's modal position |
| `qualifying_roll_calls` | Roll calls where at least eight other members voted and at least 60 percent took one position |
| `rate_percent` | Departures over qualifying roll calls |

## general_debate_terms.csv

One row per state per year, with the address length in words and raw counts for twelve
stemmed patterns. `the_other_capital` counts Moroccan mentions of Algeria and Algerian
mentions of Morocco. Rates in the paper are counts per 10,000 words.

## speech_similarity.csv

| Column | Meaning |
| --- | --- |
| `year` | Calendar year |
| `morocco_algeria_cosine` | Cosine similarity of the two TF-IDF vectors |
| `median_dyad`, `p90_dyad` | Median and 90th percentile of all dyads that year |
| `speeches_that_year` | Addresses in the corpus for that session |
